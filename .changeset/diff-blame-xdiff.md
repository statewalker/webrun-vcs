**Diff and blame output byte for byte as git's, on the xdiff port.**

`@statewalker/vcs-utils`: the xdiff port takes git's whitespace flags (`ignoreWhitespace` `-w`, `ignoreWhitespaceChange` `-b`, `ignoreWhitespaceAtEol`, `ignoreCrAtEol`), and gains xdiff's emitter: `unifiedDiff`/`unifiedDiffHunks` print the hunks of `git diff` (context, inter-hunk context, `-W`, `--ignore-blank-lines`, function lines in hunk headers cut at 80 bytes and at broken UTF-8 as git does, `\ No newline at end of file`), `diffLineCounts` counts as the diffstat does, and `xdiffHunks` gives the changes `git blame` uses (common tail trimmed). `userdiffFindFunction` and `BUILTIN_FUNCNAME_PATTERNS` port git's diff drivers (builtin `cpp`, `python`, `java`, ... patterns of git 2.56, and `diff.<driver>.xfuncname`/`funcname`), running the POSIX patterns translated to JavaScript (`posixToJsRegExp`). `legacyMinimal` reproduces git before 2.5x, whose `minimal` still set aside many-matched lines. Breaking: the JGit-style `HistogramDiff`, `HistogramDiffIndex`, `MergeAlgorithm`/`merge3Way`, `getAlgorithm`, `DiffAlgorithm` and `DEFAULT_ALGORITHM` are removed (nothing used them; diffs and merges run on `xdiff` and `mergeLines`); `SupportedAlgorithm`, `MyersDiff`, `RawText` and `RawTextComparator` stay.

`@statewalker/vcs-commands`: `DiffCommand.callText(format)`/`callBytes(format)` print `git diff` as git does: the patch (`diff --git`, `old mode`/`new mode`, `new file mode`, `deleted file mode`, `similarity index`/`rename from`/`rename to`, `index` lines with abbreviated ids, `Binary files ... differ`, quoted paths, a file turned into a symbolic link as a deletion and an addition), `stat` (git's widths; `setOptions({ stat: { width } })` for `COLUMNS`), `numstat`, `shortstat`, `name-only` and `name-status`, with `setOptions` for `-U`, `--inter-hunk-context`, `-W`, `--diff-algorithm`, `--[no-]indent-heuristic`, the whitespace options and `--ignore-blank-lines`, and the configuration (`diff.algorithm`, `diff.indentHeuristic` default on, `diff.context`, `diff.interHunkContext`, `diff.renames` default on, `diff.renameLimit`, `core.quotePath`, `diff.statNameWidth`, `diff.statGraphWidth`, `diff=<driver>` attributes with `diff.<driver>.binary`/`.algorithm`/`.xfuncname`). `git diff` without trees now compares the index with the worktree (it compared HEAD with itself), `setOldTree(a)` alone compares `a` with the worktree (it compared `a` with HEAD), and paths sort in git's byte order; `setRenames(true)` detects renames in `call()`. `formatNoIndexDiff` prints `git diff --no-index` for two files. `DiffFormatter` now prints exactly git's text: `toString` ends lines with LF, `formatAll` concatenates, `formatBytes` keeps non-UTF-8 content, hunks start at 0 for an empty side (`@@ -0,0 +1,3 @@`), hunk lines include the `\ No newline at end of file` marker, and the default algorithm is myers as git's. `BlameCommand` is a port of git's blame (`blame.c`): commits by committer date, whole-file renames followed by default (git's default; `setFollowRenames(false)` is `--no-follow`), the xdiff diff with `diff.algorithm` and the indent heuristic, root commits as boundaries (`setShowRoot`, `blame.showRoot`), `setIgnoreWhitespace` (`-w`), `setLineRanges` (`-L`); lines are split at LF only (a CR-only file is one line, as in git). `BlameEntry` gains `previous` and `boundary`, `BlameResult` gains `content`, and `formatBlamePorcelain` (`--porcelain`, `--line-porcelain`) and `formatBlame` (default output, `-n`, `-f`, `-e`, `-s`, `-l`, `-t`, `-b`) print them as git does. Options for older git: `histogramRediff`, `legacyMinimal`, `renameCountLastSpan`, `namesFromContents` (diff) and `setCompatibility` (blame), `alwaysWidenAbbrev` (blame output).
