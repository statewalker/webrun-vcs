Bundles (statewalker/statewalker-root#351): `git bundle create`, `verify`, `list-heads` and `unbundle`, formats v2 and v3 (`@object-format=`, `@filter=`). `git.bundleCreate()` takes `git bundle create`'s rev-list arguments (`addArgument`, `setStdin`, `setVersion`) and returns the bundle's bytes: the walk's boundary as `-<id> <subject>` prerequisites, each positive argument naming one ref as a ref line (git's warning for a commit the rev-list options left out, `Refusing to create empty bundle.`), a thin pack of what they reach; v3 for SHA-256 repositories and `--filter`. `bundleVerify()`, `bundleListHeads()` and `bundleUnbundle()` take the bundle's bytes (`setBundle`) and print what git prints (missing or unconnected prerequisites, `<file> is okay`); unbundle keeps the pack (a filtered bundle's as a `from-bundle` promisor pack) and lists the refs. A path to a bundle file is a remote for `fetch`, `clone` (with git's `<path>.bundle` lookup; a filtered bundle is refused, `cannot clone from filtered bundle`), `pull` and `ls-remote`: its refs are advertised in git's order and its pack handed over once the repository has the prerequisites; `push` to one fails as git's. `clone` now guesses the remote HEAD's branch when the remote names no symref (guess_remote_head), and warns `remote HEAD refers to nonexistent ref, unable to checkout` when nothing can be checked out. `RevListCommand.setIgnoreMissing` is `--ignore-missing`. vcs-working-tree: `Worktree.readLocalFile` (a regular file a local remote path names); vcs-store-files implements it.
