**`git apply`, `git format-patch` and `git am`, byte for byte as git.**

- **ApplyCommand** (`git.apply()`): a port of apply.c. It reads git diffs (renames, copies, mode changes, new and deleted files, quoted names, `GIT binary patch` literal and delta hunks, `\ No newline at end of file`) and traditional unified diffs (`-p<n>` guessed or given, `--directory`). It applies them to the worktree, to the index and worktree (`--index`) or to the index alone (`--cached`), with offsets, reduced context (`-C<n>`), `--unidiff-zero`, `--recount`, `--inaccurate-eof`, `-R`, `--reject` (`.rej` files), `--3way` (`--ours`/`--theirs`/`--union`), `--include`/`--exclude`, `--allow-empty` and `-N`. `--check`, `--stat`, `--numstat` and `--summary` report without applying. Whitespace follows `--whitespace=nowarn|warn|fix|error|error-all`, `apply.whitespace`, `core.whitespace` and the `whitespace` attribute, with git's warnings. Errors and `-v` messages match git's wording, git 2.46's `<file>:<line>` locations by default and the older `line <n>` with `setLegacyMessages`.
- **FormatPatchCommand** (`git.formatPatch()`): commits as mails. It supports numbered subjects, `--subject-prefix`, `--rfc`, `-v`, `--start-number`, `-k`, `--signoff`, `--cover-letter` (with shortlog and diffstat), `--thread`/`--in-reply-to`, `--to`/`--cc`/`--add-header`, `--from`, `--base` (prerequisite patch ids), `--zero-commit`, `--no-stat`, `--no-binary`, `--numbered-files`, `--suffix`, `--filename-max-length`, `-o` and `--stdout`, and the `format.*` settings. Signatures use an injectable version string (default `2.56.0`), and an injectable clock sets the Message-ID times.
- **AmCommand** (`git.am()`): mailboxes applied one commit per mail. It handles mailsplit (mbox, mboxrd, `--keep-cr`) and mailinfo (RFC 2047, charsets, quoted-printable and base64, multipart, in-body headers, scissors, `-k`/`-b`, `-m`), and keeps git's `.git/rebase-apply/` state. It sets `ORIG_HEAD`, writes the `am: <subject>` reflog lines and prints git's messages and advice (git 2.4x's stdout advice with `setLegacyMessages`). It supports `--3way` through a fake ancestor and merge-ort, `--continue`/`--resolved`, `--allow-empty`, `--skip`, `--abort`, `--quit`, `--signoff`, `--empty`, `--ignore-date`, `--committer-date-is-author-date`, and passes `-C`/`-p`/`--whitespace`/`--reject` through to apply. Hooks and rerere are not run.
- `git log`'s email format takes format-patch's mail settings (`LogOutputOptions.mail`). Diffs can show binary files as `GIT binary patch` hunks (`binaryPatch`, git's `--binary`), deflated and delta-encoded as git does. `appendSignoff` takes git's dedup flag, and `patchIdOfChanges` computes the patch-id of a change list that holds renames.
