**New `git.fsck()` and `git.verifyPack()` porcelain, with git's checks, messages, output order and exit status.**

- **vcs-commands (`FsckCommand`):** `git fsck` after git's `builtin/fsck.c` and `fsck.c`. Every stored object is read and checked with git's message ids, severities and texts (`error in tree <id>: duplicateEntries: contains duplicate file entries`): trees (modes, zero-padded modes, order, duplicates, `.`, `..`, `.git` under its HFS+/NTFS spellings, full and empty names, null ids, symlinked `.gitmodules`/`.gitattributes`/`.gitignore`/`.mailmap`), commits (header order, tree and parent ids, author and committer lines, dates, time zones, NUL bytes), tags (object, type, tag name, tagger, gpgsig, extra headers) and `.gitmodules`/`.gitattributes` blobs. `fsck.<msg-id>` config, `setMessageType` and `setStrict` (`--strict`) set severities. Then everything reachable from the refs, the reflogs, the index (entries, cache-tree, resolve-undo), linked worktrees' HEADs and indexes, and the stash is walked; `missing`, `dangling` (default) and `unreachable` (`setUnreachable`) objects and `broken link`s are printed in git's order (the layout of git's object hash table). Options: `setConnectivityOnly`, `setDangling`, `setReflogs`, `setNameObjects`, `setRoot`, `setTags`, `setLostFound`, and `setCompatibility("2.43" | "2.56")` for the output differences between git versions. The result has the structured findings, git's stdout and stderr text, and git's exit bits (`FSCK_ERROR_OBJECT`, `FSCK_ERROR_REACHABLE`, `FSCK_ERROR_PACK`, `FSCK_ERROR_REFS`). Over a files repository (`setRepositoryFiles`) loose objects are read from their files (zlib errors, headers, `hash-path mismatch`, stray files) and packs are verified as git's `verify_pack` does (idx and pack checksums, per-entry CRC-32 and hash); over the memory, KV and SQL stores the objects of `history.objects` are checked and walked. Contents are read one object at a time.
- **vcs-commands (`VerifyPackCommand`):** `git verify-pack` with `-v` (`<id> <type> <size> <size-in-pack> <offset> [<depth> <base>]`, the `non delta:` and `chain length = N:` histogram, `<pack>: ok`) and `-s`; a bad pack is reported with its checks' own messages and `<pack>: bad`.
- **vcs-core:** `isDotGitComponent` (git's `is_hfs_dotgit` / `is_ntfs_dotgit`) is exported.
