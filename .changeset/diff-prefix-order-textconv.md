**`git diff` path prefixes, order file and textconv, as git prints them.**

- **Prefixes:** `DiffCommand` reads `diff.noprefix`, `diff.mnemonicPrefix` (`i/` and `w/` for the index against the worktree, `c/` and `w/` for a commit against it, `c/` and `i/` for `--cached`, `a/` and `b/` between two trees, the combined diff of a conflicted path included) and `diff.srcPrefix` / `diff.dstPrefix` (git 2.45+). New options `noPrefix` (`--no-prefix`) and `defaultPrefix` (`--default-prefix`, which gives `a/` and `b/` whatever `diff.srcPrefix` / `diff.dstPrefix` say) join `srcPrefix` / `dstPrefix`. A prefix that needs quoting is quoted with its path, as git's `quote_two_c_style` (`"\303\244/a.c"`), in the `diff --git`, `---` / `+++` lines and the combined diff.
- **Order file:** `diff.orderFile` and the option `orderFile` (`-O<orderfile>`) reorder the files of every output format as `diffcore-order.c` does (wildmatch on the path and its leading directories, first matching pattern, unmatched last, stable). A relative path is read from the worktree's root (one outside it, `../x`, through the host environment from the worktree's host path, `FileWorktree.hostPath`; without a worktree, from the git directory's, `GitWorkingCopyConfig.hostGitDir`); a missing file fails with git's message, and `diff.orderFile=~/x` without a home directory with git's "failed to expand user dir". `parseOrderFile`, `orderRank` and `orderByPatterns` are exported.
- **Textconv:** `diff.<driver>.textconv` (with `.cachetextconv`; no cache is kept, which changes nothing in the output) converts both sides of a patch and of a combined diff, reading them as git's `prepare_temp_file` writes them (a blob smudged as checkout writes it, `eol` and filter drivers included; a worktree file as it is, not cleaned; `DiffSideSpec.readTextconvInput`), a converted side never being binary (`diff.<driver>.binary` and `-diff` still apply to the other cases); the option `textconv` is `--textconv` / `--no-textconv`. Running the command is the host's job: `installTextconvRunner(workingCopy, runner)` registers a `TextconvRunner`; without one no textconv applies (git's `--no-textconv`), where git would fail.
- **Fixes:** `--stat` and `--numstat` count binary files in bytes even with `--text`, as git does; the `diff` attribute's driver applies to regular files only (an absent side, a symbolic link and a submodule take the default driver, as `diff_filespec_load_driver`).
