**New: `installPack(files, packDir, stream, options?)`**, git's `index-pack --stdin --fix-thin` over a `FilesApi`. The pack is stored as `tmp_pack_*`, read once, its deltas resolved through a bounded base cache and a bounded read window, and installed as `pack-<id>.pack` then `pack-<id>.idx`; the `.idx` is byte-identical to `git index-pack`'s. Thin packs are completed through `externalBase` (each missing base looked up once, verified against its id, appended; the pack gets a new count and trailer). Corrupt or hostile packs (bad trailer, truncation, trailing bytes, inflate bombs, delta cycles, missing bases, objects over `maxObjectSize`, streams over `maxPackSize`) are refused with the new `PackError` (a `CorruptObjectError`) and leave nothing behind. Also new: `sweepPackTemporaries(files, packDir, olderThanMs, now?)` removes stale `tmp_*` files as `git prune` does, and `writePackIdx(entries, packChecksum)` writes an `.idx` v2 as git does. Types: `ExternalBase`, `InstallPackOptions`, `InstalledPack`, `PackIdxEntry`.
